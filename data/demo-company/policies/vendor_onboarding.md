# Vendor Onboarding Policy

Organization: demo-company
Version: 1
Purpose: Demonstration only

## Required information

Before submitting a vendor, collect:
- Legal business name
- Contact email
- Registered address
- Service category

## Procedure

1. Read the supplied vendor documents.
2. Check that all required information is present.
3. Search existing vendors for a possible duplicate.
4. If information is missing or conflicting, ask the user.
5. Prepare the vendor record.
6. Obtain human approval before creating the record.
7. Submit the approved information.
8. Reopen the saved record and compare all required fields.
9. Report the vendor ID and verification results.

## Restrictions

- Never invent missing information.
- Never create a duplicate vendor knowingly.
- Approval applies only to the exact information reviewed.
- If that information changes, request approval again.
- Do not mark the task completed unless verification succeeds.
